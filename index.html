Simple Navigation Menu

This index.html file acts as a main menu to navigate between different HTML pages in the same folder. Click on any option below to navigate to the corresponding page.

How to Use This Menu

1. Place this index.html file in the same folder as your other HTML files.

2. The menu above will automatically show links to all HTML files in the folder (excluding index.html).

3. Click on any menu card to navigate to that page.

4. To add new pages, simply create new HTML files in the same folder and refresh this page.
